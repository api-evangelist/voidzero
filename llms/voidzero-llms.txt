# VoidZero

> VoidZero is the JavaScript tooling company building a unified, high-performance
> open-source toolchain for web development — the build tool (Vite), test runner
> (Vitest), bundler (Rolldown), and language toolchain (Oxc / oxlint) — plus the
> commercial unified entry point Vite+. Founded by Evan You (creator of Vite and
> Vue.js) and backed by Accel and Peak XV; VoidZero joined Cloudflare in 2026.
> VoidZero publishes developer tools as open-source npm packages rather than a
> hosted REST API.

## Products
- [Vite+](https://viteplus.dev): The unified toolchain and entry point for web development.
- [Vite](https://vite.dev): The build tool for the web.
- [Vitest](https://vitest.dev): Next-generation testing framework powered by Vite.
- [Rolldown](https://rolldown.rs): Fast Rust-based JavaScript bundler.
- [Oxc](https://oxc.rs): The fastest JavaScript language toolchain (includes oxlint).
